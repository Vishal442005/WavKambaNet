# Checkpoints Directory

This directory stores PyTorch Lightning model checkpoints for **Wav-KambaNet** across the PhysioNet 10-subject cohort.

### Included Checkpoints
- `subjS001-fold0-val/`: Validated best checkpoint for Subject 1 (Fold 0).
- `subjS002-fold0-val/`: Validated best checkpoint for Subject 2 (Fold 0).

### Checkpoint Structure & State Dict Keys
Each `.ckpt` contains the full PyTorch Lightning state dictionary, optimizer states, and hyperparameter configuration:
- `model.spatial_encoder.cheb_convs.*`: Dynamic Chebyshev Graph Convolution parameters ($K=3$).
- `model.spatial_encoder.learnable_adj_param`: Learned 64x64 dynamic spatial adjacency matrix.
- `model.spectral_encoder.scale`, `shift`, `wavelet_weight`: Multi-scale continuous Morlet wavelet basis splines (16 learnable wavelets).
- `model.temporal_encoder.*`: Pure Bidirectional Mamba State-Space Model weights ($d_{\text{state}}=16, E=2$).
- `model.classifier.*`: Linear projection head.

All 50 full 5-fold cross-validation checkpoints across subjects $S_1$ to $S_{10}$ are generated by running:
```bash
python scripts/train.py --cohort
```
